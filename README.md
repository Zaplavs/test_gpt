# DentaLux — Сайт премиальной стоматологии

Современный, адаптивный сайт для стоматологической клиники с премиальным дизайном.

## Особенности

- 🎨 **Современный дизайн** — градиенты, анимации, плавные переходы
- 📱 **Полная адаптивность** — отлично смотрится на всех устройствах
- ⚡ **Интерактивность** — плавная прокрутка, анимации при скролле, слайдер отзывов
- 🦷 **Тематика стоматологии** — все разделы адаптированы под клинику

## Структура сайта

1. **Главный экран** — привлекательный заголовок, статистика, CTA-кнопки
2. **Услуги** — 6 карточек с описанием услуг клиники
3. **О нас** — преимущества клиники, опыт работы
4. **Врачи** — карточки специалистов с контактами
5. **Отзывы** — слайдер с отзывами пациентов
6. **Запись на приём** — форма для записи на консультацию
7. **Контакты** — адрес, телефон, режим работы, карта
8. **Футер** — навигация и контактная информация

## Технологии

- HTML5 — семантическая разметка
- CSS3 — переменные, Grid, Flexbox, анимации
- JavaScript (Vanilla) — интерактивность без зависимостей
- Google Fonts — Inter и Playfair Display

## Запуск

Просто откройте `index.html` в любом современном браузере.

```bash
# Или используйте локальный сервер
python -m http.server 8000
# Затем откройте http://localhost:8000
```

## Файлы

- `index.html` — основная разметка сайта
- `style.css` — все стили и адаптивность
- `script.js` — интерактивность и анимации
